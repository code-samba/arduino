# Aquare - Arduino IOT

## Bibliotecas
No Arduino IDE, devem ser instaladas as seguintes bibliotecas:

- `Adafruit ST7735 and ST7789 Library` - Adafruit
- `Adafruit GFX Library` - Adafruit
- `Adafruit BMP280 Library` - Adafruit

## Esquema
O projeto está replicado no [Tinkercad](https://www.tinkercad.com/dashboard), e você pode acessa-lo [Clicando Aqui](https://www.tinkercad.com/things/iRB1RvU6AIa-samba-code-aquare).
